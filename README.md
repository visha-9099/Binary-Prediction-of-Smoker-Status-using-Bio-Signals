Binary Prediction of Smoker Status using Bio-Signals 🚬📊
📝 Project Overview
This project focuses on building a binary classification model to predict an individual's smoking status (Smoker/Non-Smoker) based on bio-signals.
By leveraging physiological and biological data, we aim to uncover patterns that distinguish smokers from non-smokers using machine learning techniques.

🔬 Problem Statement
Smoking is a major public health concern, contributing to several chronic diseases. 
Traditional methods of identifying smokers rely on self-reports or medical tests, which may not always be reliable or feasible.
This project explores whether bio-signal data (such as heart rate, oxygen saturation, and other physiological metrics) can serve as an objective indicator of smoking behavior.

📊 Approach & Methodology
Exploratory Data Analysis (EDA): Understanding data distribution, missing values, and feature importance.

Feature Engineering: Creating meaningful features that enhance prediction accuracy.

Data Preprocessing: Handling missing values, normalization, and balancing data if necessary.

Model Selection & Training:

Logistic Regression

Random Forest

Support Vector Machines (SVM)

XGBoost

Neural Networks

Evaluation Metrics:

Accuracy, Precision, Recall, F1-Score

ROC-AUC Score for model performance comparison

Hyperparameter Tuning: Optimizing models to improve predictive power.
